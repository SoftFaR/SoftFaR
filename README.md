## Tentang

Halo <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f44b/512.gif" alt="👋" width="22" /> Saya Fadil, biasa dipanggil Dil. Saya mengerjakan frontend web dan desain UI, kebanyakan dengan HTML, CSS, dan JavaScript murni tanpa framework.

Soal desain, saya suka yang tenang dan minimalis. Animasi boleh ada, asal punya alasan.

Selain itu saya bekerja dengan tooling AI (Claude, Gemini, Cursor). Saya masih belajar, dan cara belajar saya adalah membuat sesuatu lalu memperbaikinya.

## SoftSpace

SoftSpace adalah nama yang saya pakai untuk [portfolio](https://softspace-portofolio.vercel.app/) dan konten belajar coding. Salah satunya seri Reels animasi stick-figure dengan maskot bernama Stephan, dibawakan dengan bahasa Indonesia yang santai.
